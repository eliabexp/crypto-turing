# Introdução à criptografia

Este repositório contém materiais e códigos utilizados na disciplina "Tópicos Especiais de Engenharia de Software", tratando do assunto Introdução à Criptografia, ministrada durante o semestre 2026/1 pelo professor Lindomar na Universidade de Brasília.

O objetivo é fornecer uma base sólida para entender os conceitos fundamentais da criptografia, incluindo algoritmos de cifragem, técnicas de criptografia simétrica e assimétrica e práticas recomendadas para segurança de dados.

O uso, reprodução e distribuição dos materiais contidos neste repositório são totalmente livres, dispensando a necessidade de autorização prévia ou créditos de atribuição.

# Introduction to Cryptography

This repository contains materials and code used in the course “Special Topics in Software Engineering,” covering the subject Introduction to Cryptography, taught during the 2026/1 semester by Professor Lindomar at the University of Brasília.

The goal is to provide a solid foundation for understanding the fundamental concepts of cryptography, including encryption algorithms, symmetric and asymmetric cryptography techniques, and best practices for data security.

The use, reproduction, and distribution of the materials contained in this repository are completely free, requiring neither prior authorization nor attribution.
